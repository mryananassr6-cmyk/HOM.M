**Project Architecture & Modules
the project is built using a clean, modular python architecture:
* **'mainy.py'**:the central application entry point that initializes the system and coordinates between different module.
* **'finance.py'**: Handles property financial logic, such as checking rent dues and managing payments.
* **'chat.py'**: Manages user interactions and handles incoming chat messages/inquiries
* **ai_maintenance.py'**: Utilizes AI logic to classify and process maitenance requests automatically.
